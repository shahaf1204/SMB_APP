# אפליקציית ניהול עסק (MVP)

אפליקציית ווב בעברית (RTL, Mobile First) לניהול אירועים, קטגוריות מותאמות והכנסות/הוצאות — לפי אפיון MVP.

## התקנה

```bash
cd "C:\Users\Guy Cohen\projects\smb-business-app"
npm install
npm run dev
```

פתחו את הכתובת שמוצגת בטרמינל (בדרך כלל `http://localhost:5173`).

**שימו לב:** כתובת השורש `/` מפנה אוטומטית למסך ההתחברות או לדשבורד. אם רואים מסך לבן — רעננו את הדף (Ctrl+F5) או גשו ישירות ל־`http://localhost:5173/auth`.

## יכולות MVP

- הרשמה/התחברות מקומית (localStorage)
- פתיחת עסק + 9 סוגי עסק עם קטגוריות ברירת מחדל
- ניהול קטגוריות (הוספה / מחיקה)
- הוספת אירוע + EventValues אוטומטיים
- דשבורד: אירוע קרוב, 8 פילטרי תקופה, KPI, גרפים

## מחוץ ל-MVP

עריכת/מחיקת אירועים, לקוחות, PWA — לפי Roadmap באפיון.
